# Account data for the 7.27 premium UI

Reece, 19 October 2026. For Dan, based on his 7.27 home-screen mockup (globe, flight card, operations strip, timeline).
It lists which panels can show real account data today, through which call, and which have nothing behind them yet.
Tracking, OOOI, Map V2 and PIREP stay yours. Nothing here touches them.

## Real today

All calls are on `DesktopAccountSession`. Each refreshes a rejected token once and works for any active member
unless noted.

| Mockup panel | Source | Notes |
|---|---|---|
| Name, avatar, initials (header) | `session.Bootstrap.Account`, `Bootstrap.Profile` (avatar URL, initials) | Already cached for offline use. |
| Role under the name ("Chief Pilot") | `Bootstrap.Airlines[i].Roles` for the selected `Workspace` | Roles are Pilot, Dispatcher, Administrator, Owner. "Chief Pilot" isn't a role; show the highest one or ask Reece for a title field. |
| Airline name, callsign, logo | `Bootstrap.Airlines[i]` | Personal workspace has no airline. |
| Network (route list, route lines) | `ListRoutesAsync(airlineId)` | Origin, destination, departure UTC, block minutes, weekday mask, type. |
| Fleet | `ListFleetAsync(airlineId)` | Registration, type, name, home base, status (`active`, `maintenance`, `retired`). |
| Today's Operations timeline | `AirlineSchedule.Between(routes, from, to)` in `Alpha6Ops.Identity` | Dated legs with departure and arrival UTC. Handles legs crossing midnight and legs still airborne at the window start. Planned times only. |
| "Scheduled today" count | `AirlineSchedule.Between(routes, today 00:00Z, tomorrow 00:00Z).Length` | Planned legs for the whole airline, not flights flown. |
